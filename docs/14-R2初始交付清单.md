## 1. “初始交付完成”指什么

本清单确认第一版 Vector owner / CSR-only restore 行为在既定测试中形成闭环：默认可以
关闭，开启后能减少完整数据寄存器恢复，已覆盖条件不满足时会退回 full restore。

2026-10-20 后续 R3 源码审计发现 preemptible kernel Vector task 恢复执行的失效旁路，详见
`docs/15-R3扩展失效边界源码审计.md`；M1D 已补上失效，并完成 V=y/V=n 完整构建及同 CPU
定向交错验证。因此本清单恢复为 **R2 初始行为交付完成**。

它不等于整个 OSPP 项目已经完成。产出 6 还需要继续检查 signal/ptrace、软中断、可抢占
kernel Vector 和 PM 等扩展边界；产出 7 还需要把最终不变量、安全论证和后续测试统一整理；
真实性能收益仍需 RISC-V Vector 硬件验证。
